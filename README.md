# Newsletter Builder

A one-page tool for writing Abby & Owen's supporter newsletter and pasting it into Outlook.

1. Fill in the titles, paragraphs and photos. The preview updates as you type.
2. Press **Copy for Outlook**.
3. In Outlook, start a new email, click in the message area and press ⌘V (Ctrl+V on Windows).

Drafts are saved only in the browser you're using; nothing is sent to this site.

The fixed images in `img/` are only for the preview. The email itself loads the original
header, separators and signature from proofs.advisorsexcel.com.
